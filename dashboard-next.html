How this is measured

Buy slip % = ((weighted avg buy price ÷ mid) − 1) × 100, and the same for sell. Each point walks the visible order book cumulatively until 100k USDT is consumed, clipping the boundary layer.

Mid is itself a small depth walk — the average of 1k USDT walked on each side, not raw best ask / best bid — so a lone dust order at the touch can’t distort the reference. Points inside the last hour are 5-second snapshots; older points are hourly averages.

How this is measured

A ±0.071% band around live mid — that percent is 1₦ ÷ 1400₦ target price, applied multiplicatively so the band tracks mid. Per 5-second poll, a side scores 1 if at least 100k USDT of resting size sits within its band, else 0. Each hourly point is the fraction of that hour’s usable polls that passed. The marked point is the in-progress hour, the same value shown live above. A poll where one side of the book was empty doesn’t count either way.

The dashed line is spread ≤ ₦1 compliance: on the same poll, the raw top-of-book gap scores 1 if it’s within ₦1. It’s a fixed ₦1 so stored history stays comparable. Hours recorded before this metric shipped show a gap rather than 0%.

How this is measured

Each bar is one closed WAT hour of base volume — USDT traded, straight from the exchange’s hourly candle. It is not the naira turnover D1 thresholds on. The current hour is never a bar; on the 1h range the card above covers “right now” with a trailing 60 minutes rebuilt from 1-minute candles.

The exchange serves 300 candles per request, so a live fetch reaches ~12.5 days back; older hours come from the monitor’s own archive. Over 14 days the bars switch to daily sums. The CSV export stays hourly.
